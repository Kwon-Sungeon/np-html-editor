# NP HTML 편집기

HTML 파일을 열고 화면에서 직접 수정한 뒤 원래 파일에 저장하는 Windows 프로그램입니다.

## 다운로드

[최신 버전 다운로드](https://github.com/Kwon-Sungeon/np-html-editor/releases/latest)

- **Setup EXE**: 설치용 파일입니다. 설치한 다음 바탕화면의 NP HTML 편집기를 실행하세요.
- **Source ZIP**: 소스 코드이며 실행용 프로그램이 아닙니다.

## 사용 방법

1. 프로그램 실행 → HTML 파일 선택
2. 문서 편집(TinyMCE) 또는 디자인 편집(GrapesJS)
3. 저장 또는 Ctrl+S → 열었던 파일에 반영

저장 직전 파일은 `.np-backup` 확장자로 보관합니다. 다른 이름으로 저장도 지원합니다.

Windows 10/11 64비트용입니다. 별도 Node.js 설치나 계정이 필요하지 않습니다.
정적 HTML 문서용이며 스크립트 기반 화면은 편집 중 실행하지 않습니다.
코드 서명이 없는 배포본이므로 Windows에서 최초 실행 경고가 표시될 수 있습니다.

## 라이선스
