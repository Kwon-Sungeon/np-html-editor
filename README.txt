NP HTML 편집기 v1.1.0
Windows 10/11 · 64비트

v1.1.0 변경 사항
- Office 스타일의 파일 화면과 홈·삽입·보기 리본 메뉴
- 최근 문서 목록과 다시 열기, 목록 지우기
- 글꼴·단락·제목 스타일 편집, 표·그림·링크 삽입
- 문서 목차, 글자 수, 50~150% 확대·축소
- 밝은 디자인 편집 패널: 서식·구조·추가
- 첫 편집 실행 취소와 모드 전환 시 스타일 중복 수정

사용 방법
1. 프로그램을 실행하고 '내 PC에서 열기'을 누릅니다.
2. 내 PC의 .html 또는 .htm 파일을 선택합니다.
3. 문서 편집(TinyMCE)에서 글·표를 수정하거나, 디자인 편집(GrapesJS)에서 배치·스타일을 수정합니다.
4. '저장' 또는 Ctrl+S를 누르면 열었던 파일이 수정됩니다.
5. 복사본이 필요하면 '다른 이름으로 저장' 또는 Ctrl+Shift+S를 사용합니다.

설치형: Setup 실행 → 설치 → 바탕화면의 NP HTML 편집기 실행
ZIP형: ZIP 전체 압축 해제 → NP HTML 편집기.exe 실행. EXE만 따로 옮기지 마세요.
Node.js, 계정, API 키를 별도로 설치하거나 준비할 필요가 없습니다.

저장과 백업
- 자동으로 원본을 덮어쓰지 않습니다. '저장'을 눌렀을 때만 반영됩니다.
- 저장 직전 파일은 같은 폴더의 '원래파일.html.np-backup'에 보관됩니다.
- 백업은 직전 저장본 1개만 유지합니다. 복구하려면 백업을 복사하고 확장자를 .html로 바꾸세요.
- 저장하지 않고 닫거나 다른 파일을 열면 저장 여부를 묻습니다.
- 다른 프로그램에서 파일을 변경한 경우 덮어쓰기 전 안내합니다.
- 기존 파일의 UTF-8, UTF-16, CP949 인코딩을 유지합니다. 다른 이름으로 저장은 UTF-8입니다.

편집 범위
- 정적 HTML 문서·보고서 편집용입니다. 원본의 스크립트, 이벤트 속성, 외부 삽입 콘텐츠는 편집 중 실행하지 않으며 저장 시 코드를 유지합니다.
- 동적 웹 앱, 스크립트로 생성되는 차트 등은 편집 화면과 실제 브라우저 화면이 다를 수 있습니다.
- 편집 엔진이 HTML 구조를 정리할 수 있으므로 복잡한 문서는 저장 후 브라우저에서도 확인하세요.
- 같은 폴더와 하위 폴더의 CSS·이미지를 불러옵니다. 상위 폴더를 참조하는 리소스는 미리보기에 나타나지 않을 수 있습니다.
- 외부 웹폰트·이미지는 인터넷 연결이 필요합니다. 보고서 내용은 서버에 업로드하지 않습니다.
- 외부 CSS 파일 자체는 수정하지 않습니다. 디자인 변경은 HTML 내부 스타일에 저장됩니다.
- 다른 폴더에 복사본을 저장하면 원본 리소스 폴더를 가리키는 base 경로가 추가될 수 있습니다. 다른 PC로 공유할 때는 관련 CSS·이미지 파일도 함께 전달하세요.

개발 빌드
Node.js 22 이상과 Windows x64에서:
  npm ci
  npm start
  npm run dist
배포 파일은 release/에 생성됩니다.


macOS 사용 안내
Apple Silicon(M 시리즈)은 arm64, Intel Mac은 x64 파일을 받으세요.
DMG를 열고 앱을 Applications(응용 프로그램)로 드래그한 뒤 실행합니다.
단축키는 Ctrl 대신 Command(⌘)를 사용합니다.
이 배포본은 임시 서명(ad-hoc)을 사용하며 Apple Developer ID 서명·공증을 받지 않았습니다.
최초 실행이 차단되면 시스템 설정 > 개인정보 보호 및 보안에서 이 앱의 실행 허용 여부를 확인하세요.
개발 빌드: macOS에서 npm ci 후 npm run dist:mac -- --arm64 (또는 --x64).
